# Weibo Collector Console · 微博采集工作台

面向服务器部署的单人微博采集管理工具。通过浏览器配置关键词和时间范围、安排采集任务、维护 Cookie 凭据池，并查看采集进度、微博正文和图片。

项目采用 **Scrapy + SQLite**，通过 **uv** 管理 Python 环境和依赖，支持在 Ubuntu 22.04 上部署。

## 功能概览

| 模块 | 功能 |
| --- | --- |
| 任务管理 | 创建任务、编辑待运行任务、复制配置、队列执行、暂停、恢复和取消 |
| 采集配置 | 多关键词、日期范围、微博类型、图片下载、请求间隔、数量上限和代理网关 |
| 运行监控 | 当前关键词、搜索时间段、页码、保存数量、失败数、累计时长和日志 |
| 凭据管理 | Cookie 添加、替换、验证、启停、手动切换及受限时轮换 |
| 内容浏览 | 正文搜索、作者与日期筛选、有图筛选、分页和微博详情 |
| 图片浏览 | 缩略图、原图放大、多图切换和单张原图下载 |
| 账号管理 | 管理员登录、网页修改密码和命令行密码重设 |

多个任务按队列依次执行，同一时间运行一个采集任务。每个任务分别保存配置、数据库、日志和断点。

## 部署

以下命令在 Ubuntu 22.04 的终端中执行。

### 获取项目

```bash
git clone https://github.com/k-giser/weibo-collector-console.git
cd weibo-collector-console
```

### 安装环境

安装 uv：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
```

安装 Python 和运行依赖：

```bash
uv python install 3.10
uv sync --locked --no-dev
```

### 启动服务

```bash
uv run --frozen --no-sync python -m weibo.admin.server \
  --data ./admin-data \
  --host 0.0.0.0 \
  --port 8080
```

在浏览器访问 `http://服务器IP:8080`。使用端口映射时，访问对应的映射地址。

| 启动参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--data` | 账号、任务、凭据和采集结果的保存目录 | `admin-data` |
| `--host` | 监听地址；`0.0.0.0` 用于通过服务器网卡访问 | `127.0.0.1` |
| `--port` | 服务端口 | `8080` |

以上命令以前台方式运行。长期部署可使用 systemd，配置方法见 [后台运行说明](docs/admin.md#后台运行)。访问范围由服务器防火墙和端口映射规则控制；跨不可信网络访问时，使用 HTTPS 反向代理。

## 登录与密码

初始登录信息：

| 账号 | 密码 |
| --- | --- |
| `admin` | `admin` |

登录后，点击右上角“修改密码”，填写当前密码、新密码和确认新密码。密码不能为空，两次新密码须一致。保存后使用新密码重新登录，采集任务继续运行。

管理员账号为 `admin`。账号配置保存在指定的数据目录中，服务启动和维护时应使用同一个 `--data` 路径。

## 采集流程

### 1. 添加 Cookie

在浏览器登录微博，打开开发者工具的 Network 面板，刷新页面，从微博请求的 Request Headers 中复制完整 Cookie。

在管理台的“Cookie 凭据池”中填写名称和 Cookie，然后点击“添加凭据”。多个凭据供任务共享使用；页面提供验证、启用、停用、替换和手动切换操作。

凭据更新在后续微博请求中生效。请求受限时，程序尝试使用下一凭据；全部不可用时暂停队列。“验证”显示登录接口当时的检查结果，搜索接口的可用性还受限流状态影响。

### 2. 配置任务

在“新建采集任务”中填写以下内容：

| 配置 | 说明 |
| --- | --- |
| 关键词 | 每行一个，分别搜索 |
| 起止日期 | 包含开始和结束当天 |
| 微博类型 | 原创、全部、热门等，默认原创 |
| 下载图片 | 将成功下载的原始图片保存到数据库 |
| 请求间隔 | 默认 10 秒 |
| 数量上限 | 按解析条目计数，0 表示不限 |
| 代理网关 | 可选，用于微博页面请求 |

保存后，任务进入“待运行”。点击“启动队列”开始采集；队列运行期间新增的任务排到末尾。结果较多时，程序按天、再按小时细分搜索范围。

### 3. 管理队列

| 操作 | 行为 |
| --- | --- |
| 暂停队列 | 当前任务继续运行，后续任务等待 |
| 暂停任务 | 等待当前任务收尾并保存断点，同时暂停队列 |
| 恢复到队列 | 将暂停、中断或失败的任务放回待运行列表；点击“启动队列”继续执行 |
| 取消任务 | 结束任务并保留采集结果；取消运行中的任务时暂停队列 |
| 编辑 | 调整待运行任务的配置 |
| 复制 | 将配置填入新任务表单，修改并保存为独立任务 |

需要调整已开始任务的关键词或日期范围时，使用“复制”创建新任务。服务重启后，中断任务显示为“待恢复”，由管理员恢复并启动队列。

凭据耗尽、数据库写入错误或磁盘空间不足时，先处理对应问题，再恢复任务。正常停止采集时，请等待程序完成收尾。

### 4. 查看进度

任务卡片展示当前搜索条件、页码、微博和图片保存数量、失败数及累计运行时长。点击“日志”查看最近的运行记录，也可以下载页面显示的日志片段。

保存数量来自任务数据库。相同微博按 ID 更新；解析条目数、页面累计次数和数据库记录数分别反映不同的处理过程。失败数包含请求异常和被丢弃的条目。搜索范围会动态细分，进度以这些实际指标呈现。

## 内容与图片

点击任务上的“查看内容”进入结果列表，采集过程中也可以浏览已保存的数据。

- **筛选**：正文包含、作者昵称或用户 ID、发布日期范围、仅看有图片。
- **列表**：按发布时间从新到旧排列，每页 20 条，使用上一页和下一页翻页。
- **详情**：查看完整正文、作者、发布时间、转评赞及其他已保存信息。
- **图片**：按保存顺序展示，点击放大后可前后切换、使用方向键或下载原图。
- **刷新**：点击“搜索 / 刷新”回到第一页读取最新结果，当前阅读内容由手动刷新控制。

正文搜索采用字面包含匹配。任务关键词显示采集配置，单条微博的原始关键词命中关系不单独记录。图片列表展示下载成功的内容；查看器通过数据库中的图片字节生成预览。

数据较多时，结合日期、作者等条件缩小查询范围，有助于更快定位结果。

## 数据存储与备份

默认数据目录：

```text
admin-data/
├── auth.json                  # 管理员账号与密码摘要
├── state.json                 # 任务与凭据配置
├── pool.json                  # 采集进程使用的凭据池
├── pool.status.json           # 凭据运行状态
└── <任务ID>/
    ├── config.json            # 任务运行配置
    ├── weibo.db               # 微博与图片数据库
    ├── checkpoint/            # 待处理请求和去重断点
    ├── progress.json          # 累计进度
    ├── crawl.log              # 采集日志
    └── process.log            # 进程输出
```

任务结果采用 SQLite 两表保存：

| 表 | 内容 |
| --- | --- |
| `weibo` | 微博 ID、bid、作者、正文、发布时间、转评赞及其他保留字段 |
| `weibo_image` | 关联微博 ID、图片序号、来源摘要和原始图片二进制 |

下载失败的图片可能留下序号空缺。图片原始 URL 在下载时临时使用，数据库通过微博 ID 和图片序号关联并读取图片。

备份时，暂停采集并停止管理服务，然后复制整个数据目录。目录包含 Cookie 原文和账号配置，应限制访问权限，并与代码仓库分开保存。数据库和完整日志可通过服务器文件工具获取。

断点用于继续处理待采集请求。微博搜索的展示范围、风控、异常页面及突然中断可能影响采集完整性，必要时可创建独立任务进行补采。

## 维护

### 更新程序

使用 systemd 部署后，在项目目录执行：

```bash
sudo systemctl stop weibo-admin
git pull --ff-only
uv sync --locked --no-dev
sudo systemctl start weibo-admin
```

### 重设密码

忘记管理密码时，停止服务后执行：

```bash
uv run --frozen --no-sync python -m weibo.admin.server \
  --data ./admin-data \
  --set-password
```

按提示输入并确认密码，再启动服务。

## 开发

Python 版本由 `.python-version` 指定，依赖定义在 `pyproject.toml` 中，解析结果保存在 `uv.lock`。`requirements.txt` 为兼容导出文件。

安装开发依赖并运行测试：

```bash
uv sync --locked
uv run --locked python -m pytest -q
```

测试使用离线页面和临时数据库，覆盖采集解析、凭据轮换、任务控制、图片存储、内容查询、登录和密码修改。

```text
weibo/
├── admin/                 # 管理服务、任务进程、内容查询及网页
├── spiders/search.py      # 微博搜索与内容解析
├── middlewares.py         # Cookie、代理和连续风控处理
├── pipelines.py           # 数据保存与图片下载
├── settings.py            # 采集引擎基础配置
└── utils/                 # Cookie、代理、日期和 SQLite 字段定义
docs/admin.md              # 部署与维护说明
tests/                     # 离线测试与页面样本
pyproject.toml             # 项目与依赖配置
uv.lock                    # 依赖锁文件
```
